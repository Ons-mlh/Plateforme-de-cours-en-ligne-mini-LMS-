Module 01

Variables et types de données

Une variable donne un nom à une valeur utilisée par le programme. Utilisez const lorsque la référence ne change pas et let lorsqu'elle doit être réaffectée. JavaScript manipule notamment des chaînes, des nombres et des booléens. 

const prenom = "Amina";
let age = 21;
const estEtudiante = true;

console.log(`${prenom} a ${age} ans.`);

Module 02

Conditions et opérateurs

Les conditions permettent d'exécuter un bloc uniquement lorsqu'une expression est vraie. Les opérateurs de comparaison et les opérateurs logiques aident à combiner plusieurs règles pour représenter le comportement attendu. 

const note = 15;

if (note >= 10) {
  console.log("Module validé");
} else {
  console.log("À revoir");
}

Module 03

Boucles et tableaux

Les tableaux regroupent plusieurs valeurs dans une même collection. Une boucle parcourt ces valeurs sans répéter manuellement le même code. La méthode forEach est particulièrement pratique pour traiter chaque élément. 

const matieres = ["HTML", "CSS", "JavaScript"];

matieres.forEach((matiere, index) => {
  console.log(`${index + 1}. ${matiere}`);
});

Module 04

Créer et utiliser des fonctions

Une fonction regroupe des instructions réutilisables. Elle peut recevoir des paramètres et retourner un résultat. Découper un programme en petites fonctions rend le code plus lisible et plus simple à tester. 

function calculerTotal(prix, quantite) {
  return prix * quantite;
}

const total = calculerTotal(12, 3);
console.log(total); // 36

Module 05

Manipuler le DOM et écouter les événements

Le DOM représente la page HTML sous forme d'objets. JavaScript peut sélectionner un élément, modifier son contenu et réagir à une action de l'utilisateur avec addEventListener, comme un clic sur un bouton. 

const bouton = document.querySelector("#saluer");

bouton.addEventListener("click", () => {
  document.querySelector("#message").textContent =
    "Bonjour et bienvenue !";
});

Module 06

Formulaires et validation

JavaScript complète la validation native des formulaires en vérifiant les données avant leur envoi. Écoutez l'événement submit, empêchez l'envoi si nécessaire et affichez un message compréhensible à l'utilisateur. 

form.addEventListener("submit", (event) => {
  if (email.value.trim() === "") {
    event.preventDefault();
    message.textContent = "Saisissez votre e-mail.";
  }
});
