Module 01

Sélecteurs et propriétés

CSS associe des règles de présentation aux éléments HTML. Un sélecteur cible un élément, puis les déclarations entre accolades définissent son apparence, comme sa couleur, sa taille ou son alignement. 

h1 {
  color: #1d4ed8;
  font-size: 2rem;
}

.introduction {
  max-width: 40rem;
}

Module 02

Couleurs et typographie

Une palette cohérente et une typographie bien choisie rendent une interface plus agréable. CSS accepte notamment les couleurs hexadécimales, RGB et HSL, ainsi que des familles de polices de secours. 

body {
  color: #172033;
  background-color: #f4f7fb;
  font-family: "Inter", sans-serif;
}

.accent {
  color: hsl(221 83% 53%);
}

Module 03

Le modèle de boîte et les espacements

Chaque élément est une boîte composée du contenu, du padding, de la bordure et de la marge. La propriété box-sizing aide à conserver des dimensions prévisibles lorsque l'on ajoute du padding et des bordures. 

* {
  box-sizing: border-box;
}

.card {
  margin: 1rem;
  padding: 1.5rem;
  border: 1px solid #dbe3ef;
}

Module 04

Organiser une interface avec Flexbox

Flexbox facilite l'alignement d'éléments sur un axe principal. Avec display: flex, on peut contrôler la direction, l'espacement et l'alignement d'une barre de navigation ou d'un groupe de cartes. 

.navigation {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 1rem;
}

Module 05

Grid et design responsive

CSS Grid crée des mises en page en lignes et en colonnes. Associé aux media queries, il permet d'adapter une grille au mobile, à la tablette et au grand écran sans dupliquer le HTML. 

.course-grid {
  display: grid;
  gap: 1.5rem;
  grid-template-columns: 1fr;
}

@media (min-width: 768px) {
  .course-grid { grid-template-columns: repeat(2, 1fr); }
}

Module 06

Transitions et variables CSS

Les variables CSS centralisent les valeurs réutilisées comme les couleurs et les espacements. Les transitions ajoutent une évolution douce lorsqu'un élément change d'état, par exemple au survol d'un bouton. 

:root {
  --couleur-principale: #2563eb;
}

.button {
  background: var(--couleur-principale);
  transition: transform 150ms ease;
}

.button:hover { transform: translateY(-2px); }
