Module 01

Structure d'une page HTML

Un document HTML commence par une déclaration de type, puis contient les éléments html, head et body. Cette structure permet au navigateur de comprendre le document et de présenter son contenu correctement. 

<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8">
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bienvenue</h1>
  </body>
</html>

Module 02

Titres et paragraphes

Les titres de h1 à h6 organisent la hiérarchie du contenu. Utilisez un seul titre principal par page, puis descendez progressivement dans les niveaux. Les balises p servent à découper le texte en paragraphes lisibles. 

<h1>Le jardinage urbain</h1>
<h2>Choisir ses plantes</h2>
<p>Les herbes aromatiques poussent facilement
sur un balcon bien exposé.</p>

Module 03

Liens et images

La balise a relie les pages entre elles grâce à son attribut href. La balise img affiche une image et doit toujours posséder un attribut alt descriptif afin de rester accessible aux personnes qui utilisent un lecteur d'écran. 

<a href="contact.html">Nous contacter</a>

<img src="images/logo.png"
     alt="Logo de LearnHub">

Module 04

Listes et tableaux

Les listes non ordonnées présentent des éléments sans classement, tandis que les listes ordonnées indiquent une séquence. Les tableaux sont réservés aux données tabulaires et doivent utiliser des en-têtes pour faciliter leur compréhension. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<table>
  <tr><th>Cours</th><th>Niveau</th></tr>
  <tr><td>HTML</td><td>Débutant</td></tr>
</table>

Module 05

Créer des formulaires

Les formulaires recueillent les informations saisies par les visiteurs. Chaque champ doit être associé à une étiquette label, et son type doit refléter la donnée attendue pour améliorer l'accessibilité et l'expérience sur mobile. 

<form action="/inscription" method="post">
  <label for="email">Votre adresse e-mail</label>
  <input id="email" type="email" name="email" required>
  <button type="submit">S'inscrire</button>
</form>

Module 06

Adopter le HTML sémantique

Les éléments sémantiques décrivent le rôle du contenu : header, nav, main, section, article et footer. Ils rendent la page plus claire pour les développeurs, les moteurs de recherche et les technologies d'assistance. 

<main>
  <article>
    <h1>Actualités du campus</h1>
    <p>Découvrez les prochains événements.</p>
  </article>
</main>
